# Если в проекте несколько AI

Если в проекте используют несколько AI-инструментов, настройте для них общие инструкции и скиллы.

## Общие инструкции

Храните общие инструкции проекта в `AGENTS.md`. Чтобы Claude Code использовал их, добавьте в `CLAUDE.md`:

```md
@AGENTS.md
```

Специфичные для Claude Code инструкции можно оставить в `CLAUDE.md`. Настройки других инструментов проверяйте по их документации.

## Общие скиллы

Для поиска и установки скиллов используйте [skills.sh](https://skills.sh/).

```bash
npx skills add <скилл>
```

Выберите нужные AI-инструменты из списка. CLI создаст для них symlink.
