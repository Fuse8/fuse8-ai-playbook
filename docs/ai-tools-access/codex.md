# Codex

## Получение доступа

1. Запросить у Антона Кнельца доступ к Codex на рабочую почту

2. Войти в ChatGPT через рабочую почту

3. В настройках аккаунта включить двухфакторную аутентификацию

4. В Codex войти через ChatGPT — для входа потребуется подтверждение номера телефона (если есть зарубежный номер, 5 и 6 шаги не нужны)

5. Купить виртуальный номер на https://hero-sms.com. Пополнить можно российской картой (можно найти номер за 10 рублей и ниже)

6. Выбрать сервис OpenAI и страну. Ввести этот номер в поле верификации Codex, запросить код. Получить SMS с кодом и ввести его для подтверждения (может прийти с небольшой задержкой, обычно до 1 минуты)
